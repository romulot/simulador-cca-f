## Q1 — Resposta correta: **B** · (5.4)

O sintoma descrito é literalmente o K1 do guia: em sessões estendidas o modelo
passa a referenciar "padrões típicos" em vez das classes específicas
descobertas antes. A causa é que os achados só existiam no histórico, e o
histórico não sobrevive à sessão longa. O conserto proporcional é persistir
cada achado **fora da janela**, ancorado em arquivo e símbolo, e **referenciá-lo**

## Q3 — Resposta correta: **D** · (5.4)

Subagentes rodam em **contexto isolado**: o que a fase 1 descobriu não chega à
fase 2 a menos que alguém sumarize e **injete** no prompt inicial. O enunciado
entrega o diagnóstico ao dizer que cada prompt contém só a própria pergunta.

- **A — errada:** camada errada. A decomposição está correta; o defeito está no que se passa entre as fases, não em como elas foram divididas.
- **B — errada:** feature plausível aplicada ao problema errado — sem `Task` os subagentes nem seriam spawnados, e o sintoma seria outro.
- **C — errada:** é o quase-certo. Mesmo que nada tivesse sido compactado, o contexto do coordenador **não** flui para o subagente; a injeção continuaria necessária.
- **D — correta.**

## Q4 — Resposta correta: **C** · (5.4)

É o K4 do guia: cada agente exporta estado para um **local conhecido** e o
coordenador **carrega um manifesto no resume**, injetando o trabalho concluído
nos prompts. É o que transforma um rerun em retomada.

- **A — errada:** o quase-certo, e o contraste que a prova cobra. `--resume` retoma uma **CONVERSA** — o histórico completo, incluindo chamadas de tool e resultados já retornados, é restaurado. Mas resumir uma conversa não é o mesmo que resumir um **TRABALHO**: um job rodando como pipeline não tem sessão interativa para retomar, e o que o crash interrompeu no meio do caminho não volta pronto. Recuperar o trabalho em si exige estado exportado para um local conhecido e indexado por manifesto — o que só a alternativa correta faz.
- **B — errada:** trata a interrupção, não o custo dela. O job continuaria recomeçando do zero na próxima falha.
- **C — correta.**
- **D — errada:** `fork_session` serve para explorar ramos divergentes a partir de um baseline, não para recuperar trabalho perdido.

- Cenário: S2 — Code Generation with Claude Code
- Princípio testado: persistência estruturada de estado; casar mecanismo ao requisito

## Q5 — Resposta correta: **A** · (5.4)

Quebra-automatismo: delegar é a resposta certa para output verboso e escopo
amplo, e a errada para um follow-up estreito sobre um arquivo que já está no
contexto. O subagente começa sem o contexto acumulado, então paga-se latência
para obter uma resposta pior — a delegação tem custo, e ele só se paga quando
há verbosidade a isolar.

- **A — correta.**
- **B — errada:** erro de volume. Passar o transcript inteiro devolve ao subagente exatamente o contexto verboso que a delegação existia para evitar.
- **C — errada:** aprofunda o mecanismo errado; o problema não é subagente raso, é subagente sem o contexto que o coordenador já tinha.
- **D — errada:** scratchpad compartilhado resolve persistência entre fases, não o custo de delegar uma pergunta trivial.
